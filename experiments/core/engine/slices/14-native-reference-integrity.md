## Late integrity and query observations

Mere assignment does not observe a target body. Preserve the existing late
errors: assignment after a competing delete is `relationTargetMissing`; delete
after a competing incoming assignment is `relationDeleteRestricted`. A target's
unrelated field update must not introduce a body-read conflict solely for
integrity. A real earlier native body/absence observation remains authoritative;
fresh integrity preparation must not refresh or replace it.

Prepare current published integrity evidence outside ordered acceptance. Validate
its suffix, refresh invalidated preparation without replaying native code, fold
every accepted-unsaved predecessor, then the entire candidate overlay. Track
actual durability predecessors when their target insertion or source removal
makes acceptance valid. Apply final source removals/retargets before restrict
checks. Same-root inserts may satisfy references; final absent sources create
no remaining target demand.

Restrict absence requires a final-state complete probe. Fetching one published
source then suppressing it via an overlay can hide a second surviving reference.
Continue until a final live violation or true EOF, using Source prefix/exhaustion
dependencies. Resource exhaustion refuses the whole operation. Public first-window
limits cannot certify integrity absence.

Forward population retains native access/hooks and detached mutable results.
`getMany` is confined to the actual loader-admitted target collection. Incoming
reads require authentic metadata/authorization and bounded indexed access.
Retarget A to B invalidates both incoming intervals; source deletion and same-key
body updates invalidate the appropriate outgoing/populated views.

The selected joint consumer reads incoming sources without a sync receipt. Its
old edge/adjacency/fact assertions and physical fault-step names are replaceable
layout assumptions. Preserve reverse results, exact dependencies, rollback and
atomic document/index/outcome evidence. Do not port the old fact engine solely
for fixture assertions. Its real query-sync readers remain named retained below.
