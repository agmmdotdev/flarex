## Logical representation and confinement

Follow the [membership divergence](../divergences/native-reference-memberships.md).
Use per-definition private logical tables only for newly admitted many-capable
definitions. A mandatory new builtin would change every bootstrap and frozen
Native10 store; this slice has no reason to do so. Scalar/optional-one source,
schema, metadata, stored hashes and allocation behavior remain unchanged.

Derive private table/index descriptors deterministically from authenticated native
declarations. Capture their role and exact complete closure in native lowering,
persisted policy and cold reconstruction. Distinguish business tables from owned
projection tables at authority and accounting owners. Public schema capture must
continue rejecting system names; merely filtering a binding DTO does not prevent
raw child CRUD. Application and framework capabilities must not grant projection
mutation or disclosure. Reuse ordinary schema/build/index owners, with no extra
physical family, installer or publication authority.

For this duplicate-free profile, stable membership identity is authenticated
declaration plus source plus target. Mutable array position is not identity.
Allocate child document IDs through the existing trusted transaction-local
generator and preserve matched IDs across reorder by indexed lookup/diff. The
array alone supplies forward order; avoid a redundant mutable order authority.
Reverse order must follow source row identity, never child IDs/creation time.
If canonical same-table source IDs are used as scalar ordering keys, prove their
ordering against decoded internal bytes rather than assuming equivalence.

Maintain derived state through the shared transaction owner for every relevant
source create/update/delete, before pending reverse reads. Coalesce the complete
final overlay, including add/remove/readd, clear, retarget, source deletion,
self-reference and insert-delete net zero. Private writes use separately bounded
internal/system work and bytes, following Source accounting; they must not consume
the 256 business-identity allowance or loosen its bound.

Public reverse traversal observes hydrated source bodies through the existing
native observation owner and verifies member/source coherence. An unrelated
source body update must retain its actual read/token conflict even when children
are unchanged. Late integrity preparation remains separate and does not create
target-body observations. Preserve true-EOF restrict probes, all accepted pending
writes and actual save dependencies.

For both reference shapes, incoming traversal now uses the existing Source query
owner with an exact consumed window of at most limit plus one. Record that prefix
or genuine EOF and actual hydrated source observations. The generic native-page
reader's minimum-sixteen prefetch is displaced mechanics, not a requirement to
observe unrelated sources beyond this window. Account actual consumed work under
both the existing request-call cap and the independent join bounds. A real request
reserves one of its 64 calls, so 63 incoming operations fit and the 64th refuses;
the older metadata-coupled incoming path used two calls per probe. Pure tests use
an explicitly larger test-only call ledger to isolate the separate 64-window and
1,088-inspection ceilings. No production limit increases. Currency/general
examined-page semantics remain with their existing owner. Preserve genuine
first-source observations: if a later fresh membership view disagrees with an
earlier observed source revision, an actual changed revision conflicts; unchanged
source/member disagreement is corruption.

Completeness comes from authenticated fresh installation, one eager all-writer
derivation owner and atomic source/member/index/outcome persistence/recovery.
Ordinary backfill indexes actual child documents; it cannot reconstruct omitted
members from source arrays. Refuse returned malformed/foreign/orphan children;
do not promise universal missing-child detection from an empty reverse query or
silently repair data through an adapter.
