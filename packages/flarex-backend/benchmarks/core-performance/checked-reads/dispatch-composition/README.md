## Observation Limits

Untraced adds no pool, Effect or frontier-membership observer; the fixture's
existing SQL observer remains where present. The traced diagnostic adds stack,
pool, named outer Effect and forwarded membership observations. Its timing has
observer overhead. PGlite is correctness only, without a PostgreSQL pool trace.

Dispatch count reductions do not establish fewer internal database statements,
server CPU or a causal latency reduction. Function/trigger statement counts,
wire/parameter bytes, internal kernel/source span counts, isolated decode CPU
and pure lock hold time remain unavailable unless separately observed. Keep the
pending-local control when interpreting timing; it does no SQL/frontier work.
No whole-request latency acceptance is claimed here.
