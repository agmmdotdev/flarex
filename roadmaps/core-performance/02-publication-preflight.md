## Component Measurement And Alternatives

Build a genuine admitted attempt with actual pending work, seal it through the
existing owner, verify it and enter finishing under original liveness. Report
these setup costs separately. Measure the real publication operation, including
fresh authority/OCC/tail checks and durable writes. Compare identical plans,
schema/profile, inputs, limits, database settings and pool/concurrency; declare
cold/warm rules, sample policy, retry and contention accounting.

Investigate projection construction, repeated immutable compilation, bounded
query composition and required row work only after attribution. Batching,
issuer reuse and map construction are hypotheses, not fixed remedies. Reject a
parallel/eager read plan that changes first refusal, a publication-prefix success
shortcut, a direct writer in the harness, a second publisher fallback, cached
live checks or weaker history/constraint proof. No transaction may span native
execution or remote effects.
