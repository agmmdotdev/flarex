## Component Benchmark And Alternatives

Construct actual authenticated pending work through genuine checked operations.
Report entry/authentication/native-work setup separately, then measure the real
seal operation and its actual detached verification owner. The compared versions
use identical profile, schema, original claim, journal workload, resource limits
and database settings. Declare cold/warm preparation, sample, cancellation/retry
and contention rules. Keep verification and capture intervals separate where
observed; nested intervals are not additive CPU attribution.

Investigate redundant immutable construction, repeated codec preparation,
bounded projection/query composition and memory copying only from concrete
evidence. A hash cache, expected-body equality shortcut, generic authenticated
registry or test-only sealed-plan producer is not an approved remedy. Shared
server captures must retain exact first refusal, row locking, size admission,
trigger tamper checks and all relevant children. Foreign callbacks and crypto
cannot be moved into an open SQL transaction to reduce crossings.
